# Celian-Website

Site personnel statique (HTML/CSS/JS), sans dépendances de build — juste des pages à ouvrir ou héberger telles quelles.

## Pages

| Fichier | Description |
|---|---|
| `index.html` | Page d'accueil animée : nom "Célian" avec un fond étoilé, effet "voyage dans l'univers" au clic |
| `check.html` | Page de vérification de sécurité |
| `404.html` | Page d'erreur 404 personnalisée (avec un petit rickroll caché 😉) |

## Stack technique

- HTML / CSS pur pour `index.html`
- [Tailwind CSS](https://tailwindcss.com/) (via CDN) et [GSAP](https://gsap.com/) (via CDN) pour `check.html` et `404.html`
- Aucun framework, aucune étape de build
